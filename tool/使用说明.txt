pads-eco  —  PADS Logic ECO 生成工具

一、准备
  1. ECN 变更表：文件名一般含 Bom&ECN-changelist，工作表 RF_ECN_Generation，
     Change Comments 列为 物料修改 / 物料删除 / 物料新增。
  2. 原理图 BOM：从 PADS Logic 导出，要带 Part Type 和 Value。
     反向检查要用导入 ECO 之后重新导出的那一版。采购 BOM / EBOM 不能用。

二、用法
  双击 pads-eco.exe：
    1. 更新器件库：点第 1 步选 CSV。表头要有「元件类型」（或「元件名称」）和「Part Number」。
       程序按文本读出这两列，写入 exe 旁 library\Electronic_components_library.xlsx。已有库时可跳过。
    2. 导入ECN：点第 2 步选变更表。
    3. 导入原理图BOM：点第 3 步，选择 PADS Logic 导出的原理图 BOM（.xlsx / .xlsm）。
    4. 生成 ECO 脚本：点第 4 步「生成 ECO 脚本」。
       生成前先做库自查：器件库至少要有「元件名称」和「Part Number」
       两列，且至少一行两列都有值；否则停止，不写 .eco。
       只有名称、没有料号的行会写在日志里（NC、安装孔、测试点常见），不因此停止。
       若变更前后封装不同（ECN Before/After Package，或 Part Type 里的封装），
       会弹出封装变化清单。请先打开 ECN 核对，确认无误后再继续；取消则不生成。
       ECO 写在 ECN 同目录、同名 .eco。通过后日志区改成操作指导：
       如何导入 ECO，以及原理图改完后怎样做反向检查。
    5. 反向检查：原理图导入 ECO 并改完后，重新导出一版原理图 BOM，点第 5 步选这份 BOM。
       第 2 步若已选带宏的 xlsm，就用那份 ECN 工具；否则再选一次 Bom&ECN-changelist.xlsm。
       程序先复制为同目录「原名.反向检查.xlsm」，只改这份备份，原 xlsm 不改。
       备份里删掉「值」带 @ 或空白的行，以及「名称」空白的行，表头放到第 1 行，整表替换 EBOM 并保存。
       然后自动做位号检查并生成 ECN。生成完成后变更表没有数据行才是 PASS（ECN 为空）。
       宏没有生成完时，备份里的 ECN 表不重写，日志写明宏的提示，不会把 ECN 判成空。
       原 BOM 不改。复制失败时请先关掉已经打开的那份工作簿。需要本机 Excel。
  通过校验显示绿色 PASS，并写出 .eco。不通过显示红色 FAIL，列出原因，不生成文件。
  同目录会多一份 .map.csv：每个位号做了什么 / 为什么跳过。

三、生成规则
  物料修改  *CHGPART*  BOM当前类型 → After 料号对应的库元件名称
  物料删除  *SET_ATTRIBUTE* PART 位号 / "Value" @原Value    （Part Type 不变）
  物料新增  *CHGPART* 经 NC 两跳到 After（同族先到 NC，再到 After）
  Value 已为 @ 的位号做修改时，同样经 NC 两跳（规避 Logic 整板同类被改的 bug）。

四、导入 PADS Logic
  备份原理图 → 断开 Layout → 关闭在线 DRC → 文件 → 导入 → 文件类型 .ECO → 选择此次生成的 ECO 文件。
  抽查：删除位号 Value 以 @ 开头、Part Type 不变；新增位号已是 After 全名。

五、亿赛通加密的 Excel
  ECN / BOM，以及器件库 xlsx，如果是亿赛通（E-SafeNet）加密文件，不用先解密：
  工具会自动识别并调用本机 Excel 在后台读取（需要装有 Excel），不改动、不重加密原文件。
  没装 Excel 的电脑会提示「需要 Excel」，此时请先解密再用。
  更新器件库时，明文 CSV 按文本读取，不打开 Excel。
  若这份 CSV 在工具里仍是亿赛通密文，则改由本机 Excel 在后台读取，不另存原文件。

六、更新器件库
  第 1 步选择的输入是 CSV，不是 Excel。至少两列：元件类型（或元件名称）、Part Number。
  程序抽出这两列，写入 exe 同目录 library\Electronic_components_library.xlsx。
  工具之后仍使用这份 xlsx。
